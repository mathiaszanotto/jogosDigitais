# Pacotes — The Blood Warfare

- **TheBloodWarfare-WebGL.zip:** jogo compilado para itch.io, com index.html na raiz.
- **TheBloodWarfare-Source.zip:** projeto Unity, assets, áudios, licenças, documentação e relatórios.
- **TheBloodWarfare-PressKit.zip:** capa 630×500 e cinco screenshots.
- **manifest.json:** tamanhos, quantidade de arquivos e hashes SHA-256.
- **PUBLICAR-NO-ITCH.md:** descrição, controles, créditos e configuração.

Unity **6000.6.6f1**, com Web Build Support.

Teste local: node Tools/serve.cjs "CAMINHO_DA_PASTA"; abra http://127.0.0.1:8080.

Músicas: ComingHome_8bit no menu e AceOfSpades_8bit no gameplay, conforme arquivos fornecidos. Créditos e licença da fonte incluídos.
